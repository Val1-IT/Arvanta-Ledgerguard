# v0.1.0 release blockers

## MUST FIX BEFORE v0.1

- Run the new GitHub Actions `integration` job on `main` (not done until merge).
- Confirm `pnpm verify:integration` on a clean clone with Docker.
- Tag `v0.1.0` only after that green CI (not part of this branch until maintainers merge).

## DOCUMENT FOR v0.1

- Demo authority is hardcoded `incident-ui` with full capabilities. Not production authentication.
- Idempotency crash window: ERP COMMIT then mark key `completed`. A crash in between leaves `reserved` / `in_flight`.
- Detector precedence: conversion mismatch wins; simultaneous root causes are not aggregated.
- DataHub is optional and outside execution authority.
- `ALREADY_EXECUTED` vs `DRIFT_DETECTED` semantics.

## DEFER POST-v0.1

- Public CLI framework.
- npm package publishing / install-from-registry path.
- OAuth / real user authentication.
- REST/ERP adapters beyond PostgreSQL.
- Distributed transaction coordinator.
- Policy DSL / user-defined policies.
- Web redesign / `apps/web` move.
