# examples/investigations

Captured, deterministic investigation outputs (structured JSON, `IncidentInvestigationReport`)
from real runs of the FASE 4 financial integrity engine against the seeded
conversion-error scenario in `ledgerguard-postgres` (PostgreSQL demo milik Arvanta
LedgerGuard). Regenerate with `npm run example`. Every value in these files comes
from the engine and the database — none are hand-written.
